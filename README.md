## ✨ Características Destacadas

-   📊 **Ranking de Pesos:** Comparativa visual moderna de las marcas más populares del mercado (Grilon3, 3N3, Printalot, etc.).
-   ⚖️ **Calculadora Pro:** Ingresá el peso actual de tu bobina y obtené los metros restantes aproximados (PLA/PETG/ABS).
-   📱 **PWA (Instalable como App):** Usá la web como una aplicación nativa en tu celular sin necesidad de tiendas.
-   🤝 **Salón de la Fama:** Reconocimiento a los miembros de la comunidad que aportan datos reales para que la base crezca.
-   📱 **Comunidad WhatsApp:** Acceso directo al grupo de Makers 3DBAT para consultas y soporte.

---

## 🛠️ Mantenimiento para Administradores

La base de datos reside en el archivo `filamentos.js`. Para agregar o modificar marcas:

1.  Abrí `filamentos.js`.
2.  Agregá una nueva línea siguiendo el formato de la constante `DATA_RAW`:
    `Marca | Variante | Peso Vacío (g)`
    *Ejemplo: `Creality | Hyper PLA | 160`*
3.  Subí el archivo a GitHub y los cambios se verán reflejados automáticamente.
